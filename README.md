# 牛客语法入门：一轮考核（Python 3）

按照[原题单](https://ac.nowcoder.com/discuss/817596)“语法入门”七类在题目汇总中的顺序，各完成前五题，共35题。每道题是可独立运行、可单独提交的 `main.py`，仅使用 Python 3 标准库。

## 运行

```sh
python3 02_选择结构程序设计/212955/main.py < input.txt
python3 tests/verify.py
```

无需安装第三方依赖。文件路径包含中文，命令行路径可加引号。

## 说明

- NC205911 题单中的旧名是“随机序列”，当前题面名为“牛牛的数学作业”，代码以相同题号的当前题面为准。
- “栈、队列和stl”分类使用 Python 列表及 itertools、functools 等标准库完成。
- NC215089 相等时输出 `Tacit！`（全角感叹号），不等时输出 `No Tacit!`。
- 图案题保留行首空格；NC16570 严格不输出末尾换行。
- 后两道比值优化题采用二分判定，避免错误地按单件比值排序。
